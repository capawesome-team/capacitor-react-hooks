# Capacitor React Hooks

React hooks for [Capacitor](https://capacitorjs.com/) plugins, maintained by [Capawesome](https://capawesome.io/).

This monorepo contains:

| Path | Description |
| --- | --- |
| [`packages/react-hooks`](./packages/react-hooks) | The [`@capawesome/capacitor-react-hooks`](https://www.npmjs.com/package/@capawesome/capacitor-react-hooks) package. |
| [`apps/example`](./apps/example) | Example app exercising every hook. |

## Development

```bash
npm install
npm run build
npm run test
npm run lint
```
